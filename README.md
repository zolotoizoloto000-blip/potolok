# Центр Потолков — FULL CMS

Рабочая CMS на Flask + SQLite.

## Что работает
- защищённый вход `/admin/login`;
- добавление товара;
- несколько фотографий (до 8);
- название, категория, бренд, описание, характеристики;
- цена, старая цена, единица измерения, «цена по запросу»;
- наличие, артикул, новинка, рекомендуемый;
- редактирование;
- публикация/скрытие;
- удаление товара и его загруженных фото;
- опубликованные товары автоматически появляются на `/`.

## Локальный запуск
`pip install -r requirements.txt`
`ADMIN_PASSWORD=ваш_пароль python app.py`

По умолчанию для локального теста пароль: `admin123`. Перед публикацией обязательно задайте `ADMIN_PASSWORD` и `SECRET_KEY`.

## Важно для Render
SQLite и локальная папка uploads на обычном ephemeral-инстансе Render могут сбрасываться при redeploy/restart. Для реального клиента подключите persistent disk либо PostgreSQL + объектное хранилище (Cloudinary/S3). Код уже отделяет API от интерфейса, поэтому это можно заменить без переделки дизайна.
