# Делай сам — демо проката строительного инструмента

Новый самостоятельный проект Flask + SQLite. Исходный проект потолков не используется: тематика, страницы, каталог и админка написаны заново.

## Запуск

pip install -r requirements.txt
ADMIN_PASSWORD='придумайте-сложный-пароль' SECRET_KEY='случайный-длинный-секрет' python app.py

Сайт: http://localhost:5000/; админка: http://localhost:5000/admin/login

## Что работает

Каталог, поиск, фильтр, расчёт цены по дням, запись заявки в БД, вход администратора, мобильное боковое меню, добавление/редактирование/удаление инструментов, загрузка фото, цены, залог, остаток, статус, список заявок, изменение статусов, название и телефон компании.

## Перед показом клиенту

Восемь инструментов, цены, залоги и описания — **демонстрационные**. Подтвердить с владельцем реальные позиции, фотографии, стоимость, залог, адрес, график, телефон, условия доставки и аренды. Контакт компании не выдуман. Заявка сохраняется в админке, WhatsApp автоматически не отправляется. Поисковая индексация не гарантируется: после публикации настроить домен, Search Console, sitemap и SEO для реальных страниц.

## Продакшен

Render без постоянного диска может потерять SQLite и загруженные фото при перезапуске/деплое. Подключить persistent disk или PostgreSQL и постоянное объектное хранилище для фотографий. Установить ADMIN_PASSWORD, SECRET_KEY и COOKIE_SECURE=1. Добавить rate limiting для входа, резервные копии и политику обработки персональных данных. Не передавайте пароль клиенту через публичную ссылку.
