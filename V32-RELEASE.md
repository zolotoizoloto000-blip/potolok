# V32 — архитектурный премиальный дизайн

Палитра: графит, тёплый белый, шампань. Полностью заменены старые конфликтующие CSS главной страницы. Manrope включён в архив и загружается локально. Обновлены композиция первого экрана, блоки решений, брендов, форма заявки, FAQ, контакты, мобильное меню и оформление админки.

## До запуска

- Загрузить содержимое архива в существующий репозиторий и выполнить деплой Render.
- Сохранить существующие переменные окружения. Нужны SECRET_KEY, ADMIN_PASSWORD, SITE_URL; для постоянных данных — DATABASE_URL и хранилище фотографий согласно PRODUCTION-CHECKLIST.md.
- Реальные товары и фотографии загружаются через админку. База данных клиента не включена в архив. Иллюстрации не выдаются за выполненные работы.
- Главная страница сейчас на русском. Полная локализация KZ/EN не выполнена.
- SEO не гарантирует позиции или поток заявок; домен и индексация настраиваются отдельно.

Дополнительно: исправлено затирание переводов товара при редактировании из админки; лимит фотографий в интерфейсе согласован с общим ограничением запроса.
