# Делай сам — прокат строительного инструмента

Проект переработан из V47 с сохранением Flask/SQLite (или PostgreSQL через DATABASE_URL), каталога, трёх языковых полей, SEO, CRM заявок, загрузки фото и защищённой админки.

## Админка
`/admin` — на мобильном устройстве навигация открывается боковой выдвижной панелью. Можно добавлять/редактировать/удалять инструменты, фото, цены, единицы аренды, наличие, категории и SEO.

## Перед публикацией
Задайте `ADMIN_PASSWORD` (или `ADMIN_PASSWORD_HASH`), `SECRET_KEY`, `SITE_URL`, постоянное хранилище/БД и реальные телефон, WhatsApp, адрес и 2GIS через админку. Демо не обещает позиции в Google: SEO подготавливает страницы к индексации, а ранжирование зависит от поисковой системы и продвижения.
