# V30: демонстрация и запуск
1. Для Render задать ADMIN_PASSWORD, SECRET_KEY, SITE_URL, DATABASE_URL (постоянная PostgreSQL).
2. Для фото задать SUPABASE_URL, SUPABASE_SERVICE_KEY, SUPABASE_BUCKET и создать публичный bucket с корректными правами. Сервисный ключ только в Render Environment.
3. Не импортировать/удалять catalog.db на работающем сервере: данные пользователей могут быть потеряны.
4. Проверить на тестовой БД: python test_demo.py; тест создаёт и удаляет товар и создаёт заявку, поэтому НЕ запускать на продакшен-БД.
5. Проверить вручную с телефона: все кнопки, формы, WhatsApp, 2GIS, добавление/удаление фото, отображение товара и перезапуск Render.
6. Заменить иллюстративные SVG на разрешённые реальные фотографии компании перед утверждением кейсов. Не обещать позиции в Google или поток заявок.
7. Проверить тексты и переводы RU/KK/EN с заказчиком; текущий интерфейс сайта преимущественно русскоязычный.
